# Programming Practice Repository

A collection of 1000 numbered code files, each solving a specific problem statement, spanning multiple languages and programming concepts. This repository serves as a personal archive of coding practice — from basic syntax to increasingly complex logic-building exercises.

## 📁 Repository structure

Each file in this repository is named using its **program number** (e.g. `1`, `2`, `3` ... `1000`), corresponding directly to the entries in the accompanying index sheet, `program_index.xlsx`.

```
├── 1
├── 2
├── 3
├── ...
└── 1000
```

## 📊 How to navigate this repository

The file `program_index.xlsx` acts as the master index for the entire repository. It maps every program number to:

| Column | Description |
|---|---|
| **Program number** | Matches the file name in this repository |
| **Problem statement** | A short description of what the program solves |
| **Language** | The programming language used (C, C++, Java, etc.) |
| **Learning** | (Optional) Key concept or takeaway from the program |

To find the code for a specific problem, open the index sheet, locate the problem statement or language you're looking for, and match the **program number** to the corresponding file in this repository.

## 🧩 What's inside

The programs progress in complexity and cover topics including:

- **Basics** — print statements, variable declarations, data types
- **Arithmetic operations** — addition, working with integers, floats, and doubles
- **Conditionals** — even/odd checks, prime number checks, perfect number checks
- **Loops & iteration** — sequence printing, ascending/descending order, divisibility checks
- **Numbers & digits** — digit counting, digit sums, reversing numbers, palindrome checks
- **Arrays** — array declaration, traversal, and indexed access
- **Object-oriented basics (Java)** — working across multiple classes, user input handling

Many problems appear more than once as iterative attempts, with the most polished/complete version marked **`FINAL-`** in the problem statement — these represent the final working solution for that concept.

Problems are solved using an **incremental approach** — each solution builds on the concept before it, starting from the simplest version of a problem and gradually adding complexity (extra conditions, edge cases, optimizations, or additional features) across subsequent program numbers. This makes the repository useful not just as a code archive, but as a step-by-step trail of how each concept was built up and understood.

## 🚀 Usage

1. Open `program_index.xlsx` and find the problem you're interested in.
2. Note its **program number**.
3. Open the matching numbered file in this repository — it contains the complete source code for that problem.
